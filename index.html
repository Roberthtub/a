01｜案例背景

PROJECT OVERVIEW

大學每學期都需要處理學生基本資料、教師開課、學生選課與學期成績。若資料分散在不同表格，容易產生重複資料、更新不一致及查詢困難等問題。

本系統以關聯式資料庫整合五種資料：學生、教師、課程、開課班級及選課成績。使用者可查詢學生修課清單、課程名單、平均成績與未及格紀錄。

系統功能

01 / DESIGN

檢視資料表、主鍵、外鍵與關聯。

02 / QUERY

使用 SQL 查詢學生、課程及成績。

03 / UPDATE

新增或修改資料，觀察資料變化。

04 / COMPARE

保存修改前結果並與修改後比較。
